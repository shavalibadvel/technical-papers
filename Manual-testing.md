##  SDTC (Software Development Test Cycle)
The set of testing activities built into each phase of software development.
It covers planning, test design, execution, defect tracking, regression, and closure.
Used so quality is checked early and often — not just at the end — which makes defects cheaper to fix.

## RTM (Requirements Traceability Matrix) — see also #6
A two-way table linking requirements ↔ test cases ↔ results ↔ defects.
Forward traceability answers "did we test this requirement?"; backward answers "why does this test exist?".
Used to prove coverage, spot gaps, and support release sign-off and audits.
